## Run locally

1. Extract the ZIP.
2. Open this folder in VS Code.
3. Open `index.html` with Live Server, or use any static local web server.
4. Test the navigation, theme toggle and all project links.

No framework, package installation or build step is required.

## Before deployment

1. Read the About section aloud and personalise it.
2. Open all three live project URLs and confirm they work.
3. Verify the three GitHub repository links.
4. Add your LinkedIn URL in `index.html` if you want it displayed.
5. Test at 320px, tablet and desktop widths.
6. Test the whole site using only the keyboard.
7. Run Lighthouse in Chrome on Mobile and reach the Full Track thresholds:
   - Performance: 90+
   - Accessibility: 95+
   - Best Practices: 90+
8. Save your actual Lighthouse screenshots in `docs/`.
9. Complete the peer review requirement separately.
