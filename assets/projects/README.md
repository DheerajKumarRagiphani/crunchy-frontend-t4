# Project screenshots (add your own)

Add your own real screenshots of Task 1, Task 2 and Task 3 here.

Recommended filenames:
- `task1-preview.webp`
- `task2-preview.webp`
- `task3-preview.webp`

Export screenshots as WebP and resize them to the dimensions actually used on the page. Do not add very large original screenshots.

When you add a screenshot to a project card in `index.html`, use an image element like this:

```html
<img
    src="assets/projects/task2-preview.webp"
    alt="ShopMart responsive product catalogue displayed on desktop"
    width="900"
    height="560"
    loading="lazy"
    decoding="async"
>
```

Write useful alt text that describes what is visible. Keep `loading="lazy"` for project images below the initial viewport. The hero section does not need a placeholder headshot.
