## Responsive and accessibility testing
- [ ] Test at 320px width.
- [ ] Test at tablet width.
- [ ] Test at desktop width.
- [ ] Use Tab and Shift+Tab to reach every interactive control.
- [ ] Confirm focus indicators are visible.
- [ ] Activate links and buttons with Enter/Space.
- [ ] Test mobile navigation with keyboard.
- [ ] Test light/dark theme toggle.
- [ ] Confirm theme preference is remembered after reload.
- [ ] Test with reduced motion enabled.
